# Configuration

`vllm-gaudi-calibrate` generates the INC configuration files for the calibration process. If you require advanced customization, you can use JSON configuration files to control aspects like scale calculation methods, module selection, and performance optimizations. The `quantization_config` directory contains JSON templates that you can use directly or modify to suit your specific requirements. Pass them to the tool with `--measure-config` and `--quant-config`. For more information, see [INC Configuration](../../docs/configuration/calibration/reference.md#inc-configuration) in the Calibration Reference and [Custom INC Configs](../../docs/configuration/calibration/advanced.md#custom-inc-configs).
